# Module 3 - Hình học 3D, đa cảm biến và Robotics Perception

**Mục tiêu đầu ra:** Hiểu chuỗi biến đổi tọa độ, tái tạo được cấu trúc 3D, xử lý point cloud và tích hợp camera–LiDAR trong một pipeline perception.

## Danh sách phân mục
- [3.1 - Hình học đa góc nhìn](./3.1 - Hình học đa góc nhìn/README.md): Pinhole Camera, Intrinsic/Extrinsic, Epipolar Geometry, Essential/Fundamental Matrix, Stereo Matching, PnP, Bundle Adjustment.
- [3.2 - Xử lý đám mây điểm với Open3D và PCL](./3.2 - Xử lý đám mây điểm với Open3D và PCL/README.md): Point Cloud Preprocessing (Voxel Downsampling, SOR), RANSAC Plane Fitting, Point Cloud Registration (ICP, Point-to-Plane).
- [3.3 - Sensor Fusion và SLAM](./3.3 - Sensor Fusion và SLAM/README.md): Camera-LiDAR Extrinsic Calibration, LiDAR Odometry (LOAM, Fast-LIO), Visual SLAM (ORB-SLAM3), Loop Closure, Drift Analysis.
- [3.4 - Deep 3D Perception cho hệ thống tự hành](./3.4 - Deep 3D Perception cho hệ thống tự hành/README.md): LiDAR 3D Detection (PointPillars, CenterPoint), Multi-Camera 3D Detection (BEVDet, PETR), Bird’s-Eye View (LSS, BEVFormer), 3D Occupancy.
- [3.5 - Biểu diễn thần kinh 3D](./3.5 - Biểu diễn thần kinh 3D/README.md): NeRF (Implicit Representation, Volume Rendering), 3D Gaussian Splatting (3DGS, Real-time rendering, COLMAP pipeline).
