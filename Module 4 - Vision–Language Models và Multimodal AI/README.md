# Module 4 - Vision–Language Models và Multimodal AI

**Mục tiêu đầu ra:** Xây dựng được ứng dụng kết hợp ảnh–văn bản, open-vocabulary detection/segmentation và hiểu kiến trúc nền tảng của Vision-Language Model.

## Danh sách phân mục
- [4.1 - Học biểu diễn đa phương thức](./4.1 - Học biểu diễn đa phương thức/README.md): CLIP, SigLIP, Contrastive Learning, Zero-Shot Classification, Text-to-Image Retrieval, Recall@K.
- [4.2 - Thị giác từ vựng mở](./4.2 - Thị giác từ vựng mở/README.md): Grounding DINO, Open-Vocabulary Segmentation (X-Decoder, Grounded-SAM), Auto-Labeling Pipeline.
- [4.3 - Kiến trúc Vision Large Language Model](./4.3 - Kiến trúc Vision Large Language Model/README.md): Vision Encoder -> Projector -> LLM Backbone (LLaVA, Qwen2-VL, Florence-2), Visual Instruction Tuning, LoRA Fine-tuning.
- [4.4 - Vision–Language–Action cho hệ thống tự hành](./4.4 - Vision–Language–Action cho hệ thống tự hành/README.md): Mô hình VLA (RT-2, PaLM-E), Action Tokenization, Robot Simulation, Out-of-distribution evaluation.
