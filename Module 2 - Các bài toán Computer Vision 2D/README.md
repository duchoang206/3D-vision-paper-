# Module 2 - Các bài toán Computer Vision 2D

**Mục tiêu đầu ra:** Huấn luyện, đánh giá và triển khai được các pipeline classification, detection, segmentation, pose, tracking và restoration trên dữ liệu thực tế.

## Danh sách phân mục
- [2.1 - Phân loại ảnh](./2.1 - Phân loại ảnh/README.md): CNN (ResNet, ConvNeXt), Vision Transformer (ViT, Swin), Transfer Learning, Augmentation, Metrics (Accuracy, F1, Confusion Matrix).
- [2.2 - Phát hiện vật thể](./2.2 - Phát hiện vật thể/README.md): Bounding Box, IoU, NMS, mAP, Two-stage (Faster R-CNN), One-stage (YOLO series), Transformer-based (DETR, Deformable DETR).
- [2.3 - Phân vùng ảnh](./2.3 - Phân vùng ảnh/README.md): Semantic Segmentation (U-Net, DeepLabV3+, SegFormer), Instance Segmentation (Mask R-CNN, Mask2Former), SAM / SAM 2, mIoU/Dice.
- [2.4 - Ước lượng tư thế và phân tích video](./2.4 - Ước lượng tư thế và phân tích video/README.md): 2D Human Pose (HRNet, RTMPose, OpenPose), Action Recognition (3D-CNN, ST-GCN), Xử lý Temporal Sampling.
- [2.5 - Theo dõi và định danh](./2.5 - Theo dõi và định danh/README.md): Multi-Object Tracking (Kalman Filter, ByteTrack, BoT-SORT), ReID (OSNet, Triplet Loss), Metrics MOTA/IDF1/HOTA.
- [2.6 - Các bài toán 2D mở rộng](./2.6 - Các bài toán 2D mở rộng/README.md): Optical Flow (RAFT), Monocular Depth Estimation (Depth Anything), OCR (DBNet + CRNN), Image Restoration (Real-ESRGAN, NAFNet).
